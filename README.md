## 📌 О проекте

Современные LLM хранят информацию о различных свойствах текста и моделируемых концептах во внутренних представлениях. Один из подходов механистической интерпретируемости - Sparse Autoencoders (SAE), они позволяют разложить плотные активации модели на набор разреженных и потенциально интерпретируемых признаков.

В рамках проекта предлагается исследовать, насколько такие признаки можно использовать не только для анализа, но и для каузального управления поведением языковой модели во время инференса без изменения её весов.

В качестве целевых свойств можно рассматривать:

- механизмы отказа от ответа (refusal behavior) и другие признаки связанные с безопасностью/цензурой;
- наличие или усиление определённых семантических концептов;
- тональность и эмоциональную окраску ответа;
- стиль и особенности генерации;
- другие языковые или поведенческие свойства модели;

Для экспериментов предполагается использовать небольшие LLM с открытыми весами и существующие публичные SAE.

## 🎯 Исследовательский вопрос

> Дают ли SAE-признаки преимущество перед простыми способами получить направление для вмешательства, и как устроен компромисс между силой вмешательства и сохранностью модели.

Все методы получения направления сравниваются на едином протоколе.

| Метод получения направления | Роль |
|---|---|
| Разница средних активаций по контрастным парам | бейзлайн |
| Веса линейного пробника | бейзлайн |
| SAE-признаки, отобранные разными способами | основной метод |
| Случайное направление | нижняя граница |

Целевой эффект и сохранность модели измеряются совместно. Результат эксперимента это кривая компромисса между ними.

| Метрика | Что измеряет |
|---|---|
| Целевой эффект | Изменилось ли нужное свойство генерации |
| Fluency | Перплексия сгенерированного текста |
| KL-дивергенция | Насколько сильно возмущено распределение модели |
| Latency | Накладные расходы на интервенцию |
